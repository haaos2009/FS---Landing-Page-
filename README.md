## Landing Page — The MET

A modern, responsive landing page created to The Metropolitan Museum of Art. This project focuses on precise markup implementation, smooth user interactions, hover effects, and modern CSS/SCSS styling techniques.

## Live Preview

- [DEMO LINK](https://haaos2009.github.io/FS---Landing-Page-/)

## Design Reference

[THE MET — Figma](https://www.figma.com/file/lSR1m42L9YwzQwzzxKwHpw/THE-MET)

## Technologies Used

**Core**

- HTML5 – Semantic markup and accessible document structure
- SCSS / CSS3 – Modular BEM architecture, responsive layout, and CSS transitions
- Parcel – Asset bundling, SCSS compilation, and local development server

**Code Quality & Formatting**

- ESLint – Code quality and linting
- Stylelint – SCSS syntax and style rules validation
- Prettier – Automated code formatting

**Deployment & Hosting**

- GitHub Pages – Public hosting and live preview deployment

## Getting started

To set up the project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/haaos2009/FS---Landing-Page-.git
   cd FS---Landing-Page-
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the project locally:

   ```bash
   npm start
   ```
